InspiArte - sitio web

Esta versión incluye 14 fotografías en la galería.

Para publicar en GitHub:
1. Entra al repositorio InspiArte.
2. Pulsa Add file > Upload files.
3. Selecciona TODOS los archivos de esta carpeta.
4. Pulsa Commit changes.

Para agregar fotografías en el futuro:
- Nombra la nueva imagen como gallery-15.png, gallery-16.png, etc.
- Súbela al repositorio.
- Agrega una nueva tarjeta <figure> en index.html siguiendo el formato de las existentes.
